Это самодельная 2D-выживалка Surv на Python/pygame
с процедурным лесом, крафтом, строительством, животными, пещерами,
сменой дня и ночи, зомби и локальной сетевой игрой до четырёх человек.
Рядом лежит отдельная графическая сцена PyLake, посвящённая
реалистичной процедурной воде. Проект не использует внешние ассеты:
вся графика, иконки, музыка и звуки создаются кодом. Код разложен
по тематическим частям, но выполняется в общем пространстве имён
surv.runtime; запуск — `python Surv.py` или `python -m surv`
